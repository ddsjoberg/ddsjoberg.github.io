Software

Open-source packages I have written or co-authored, mostly for the R programming language.

Packages I maintain

gtsummary

  • R

Publication-ready analytic and summary tables in R. Summarize data sets, regression models and more, with sensible defaults and highly customizable output.

Features
  • Summarize data frames for descriptive statistics and demographics (e.g. a Table 1), automatically detecting continuous, categorical and dichotomous variables and reporting missingness.
  • Summarize regression models, including reference rows for categorical variables and pre-filled headers such as Odds Ratio and Hazard Ratio.
  • Customize tables with formatting and styling functions: bold labels, italicize levels, add p-values, merge or stack tables side by side.
  • Report statistics inline in R Markdown and Quarto, keeping reports fully reproducible.
install.packages("gtsummary")

cards

  • R

Create Analysis Results Datasets (ARDs): a standard, machine-readable record of the statistics behind tables and figures. {gtsummary} builds its tables on {cards}.

install.packages("cards")

cardx

  • R

Extra Analysis Results Data utilities that supplement {cards}, putting statistical test and model results in the ARD format for tables, figures and reports.

install.packages("cardx")

ggsurvfit

  • R

Publication-ready time-to-event (survival) figures with ggplot2. Every function is a proper ggplot geom or stat, so it combines with any other ggplot customization.

install.packages("ggsurvfit")

Decision Curve Analysis

  • R
  • Stata
  • SAS

Evaluate and compare prediction models by their clinical consequences, using only the data set the models are tested on. Includes the {dcurves} R package and a full tutorial.

dcurves package

tidycmprsk

  • R

An intuitive interface to competing-risks analysis: cumulative incidence with cuminc(), competing-risk regression with crr(), and broom-style tidiers.

install.packages("tidycmprsk")
